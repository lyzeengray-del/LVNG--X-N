# LVNG -X Zayon Game Space

Game Space dengan floating panel ala **Zayon Game Space**, tombol bulat mengambang untuk **Auto-Clicker berbasis Shizuku** (bukan aksesibilitas), pengaturan kecepatan klik (CPS), serta tema merah crimson mendominasi dengan sedikit aksen biru tua.

## Cara Build APK Otomatis via GitHub Actions
1. Upload isi folder `LVNG-X_GameSpace_v3` ke branch `main` repository GitHub kamu.
2. Buka tab **Actions** di GitHub, pilih **Build LVNG-X Game Space APK**, lalu klik **Run workflow**.
3. Download artifact **`LVNG-X-GameSpace-debug-APK`** setelah selesai dan install di HP Android kamu!
